# UK GBP → LKR rates

Public Next.js page that compares daily GBP to LKR remittance quotes as a heatmap.

Green cells are closest to that day's best rate. Darker purple means further behind the leader.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

Import this GitHub repository at [vercel.com/new](https://vercel.com/new) and deploy. Vercel detects Next.js automatically.
